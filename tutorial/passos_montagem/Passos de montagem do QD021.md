# Passo 1 – Identificar os pés esquerdo e direito

## Peças
- Acrílico do pé esquerdo
- Acrílico do pé direito

> **Atenção**
>
> 1. Para distinguir os pés, observe a inclinação do furo do calcanhar:
>    - Inclinado para a **direita** → pé **esquerdo**.
>    - Inclinado para a **esquerda** → pé **direito**.
> 2. Durante a montagem, os furos dos calcanhares devem ficar voltados para o interior.
> 3. Remova a película protetora das peças de acrílico antes da montagem.

# Passo 22 – Ligações elétricas

## Sensor ultrassônico

| Sensor | ESP32 |
|---------|-------|
| TRIG (branco) | GPIO13 |
| ECHO (azul) | GPIO14 |
| VCC (vermelho) | 5V |
| GND (preto) | GND |

---

## Servos

Todos os servos seguem:

- Vermelho → **5V**
- Marrom → **GND**
- Laranja → **Sinal**

### GPIO dos servos

| Servo | GPIO |
|--------|------|
| Coxa esquerda | GPIO5 |
| Panturrilha esquerda | GPIO16 |
| Coxa direita | GPIO18 |
| Panturrilha direita | GPIO17 |

---

## Aviso

⚠️ Siga rigorosamente o esquema de ligação.

Uma conexão incorreta pode provocar curto-circuito e danificar a placa ESP32.
